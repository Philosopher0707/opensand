# Agent UX benchmark — how top coding agents handle the details

Checked 2026-11-23 (Asia/Calcutta). Method: primary-source web fetches of public docs, source files, CI workflows and changelogs for Claude Code, OpenAI Codex CLI/app, Cursor, Cline, OpenCode and Aider. Every row links to a source that was fetched and returned HTTP 200 on the check date. All 101 candidate links were re-checked; one dead Cursor link was dropped.

**Observed** = the behaviour is stated in, or quoted from, the linked source. **Inferred** = my interpretation of that source, not a claim the app documents. Quotes are verbatim from the linked page or file; ellipses mark omitted words. Cursor, Codex and Claude Code docs are versioned and fast-moving, so specifics may differ on an older installed build. OpenSand's own code is out of scope (Ada owns that audit).

## 3. Crash resume and session recovery

## 5. Context-limit handling (compaction)

| --- | --- | --- |

Overflow message: `Codex ran out of room in the model's context window. Start a new thread or clear earlier history before retrying.` | [developer-commands.md](https://learn.chatgpt.com/docs/developer-commands.md?surface=cli) · [config-reference.md](https://learn.chatgpt.com/docs/config-file/config-reference.md) · [error.rs](https://raw.githubusercontent.com/openai/codex/main/codex-rs/protocol/src/error.rs) |
