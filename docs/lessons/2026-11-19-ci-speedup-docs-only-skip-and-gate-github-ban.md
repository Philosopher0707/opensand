# CI speed-up: skip the heavy suite for docs-only PRs, and the gate bans `.github/` changes

- **Trap:** The CI speed-up brief said to add dependency caching and skip build/test for docs-only changes. Caching was already on `main`, and the real cost was `Verify` (`pnpm -r run build` plus every package's tests): median 71 s on Linux and 156 s on macOS across the last 10 green runs. The obvious fix is a `.github/workflows/ci.yml` edit, but `scripts/pr-gate.sh` Check 3 refuses any path under `.github/` with no override flag, so the gate would block the merge even though the owner had approved the workflow change.
- **Root Cause:** The gate treats workflow edits as untrusted because they can change what CI does with secrets; that rule predates this job and has no `--allow-github` switch. Putting the docs-only detection in the workflow also duplicates the change across two jobs. `scripts/verify.sh` is the single entry point both jobs already call, and it can read `GITHUB_EVENT_PATH` plus `git diff` to decide for itself — no workflow edit, no gate bypass, and the required check names (`Build & test (Node 22)`, `Build & test (macOS, Node 22)`) stay untouched because the job still runs and exits 0.
- **Rule:** For a "make CI faster" job, measure first: if caching is already present, optimise the step that actually costs time. To skip work for docs-only PRs, detect it in `scripts/verify.sh` (base SHA from `GITHUB_EVENT_PATH`, `git diff --name-only <base> HEAD`, all paths must match `docs/*`, `*.md`, `LICENSE*`, `NOTICE*`), fail closed to the full suite when the base cannot be resolved, and run the cheap repo checks before the skip so a stale lessons index still fails. Keep the cheap checks above the skip — they are the validation a docs change can still break. Do not try to merge a `.github/` change through `pr-gate.sh`: either the owner changes that rule first or the fix belongs in a script the workflow already calls. A local full `verify.sh` run rewrites tracked desktop screenshots — restore them before rebasing or saving (recurrence of the 2026-11-19 screenshot lesson).
