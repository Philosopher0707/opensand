# Event projection sparse array holes crash transcript formatting

**Trap:** When replaying an event log that begins with `turn.started` (missing initial snapshot/baseline), `turn.folded` events with indices past the current message array length create sparse array holes with `undefined` entries. Subsequent projections (`formatHumanReadable`) attempt to read `.role` on these undefined entries, throwing `TypeError: Cannot read properties of undefined (reading 'role')`. Because `writeProjections()` was awaited unconditionally after emitting `turn_completed`, the fatal projection error caused `runTurn` to reject and skipped `dispatchStop`.

**Root Cause:**
1. `projectMessages` directly assigned `messages[change.index] = change.message` without bounds-checking `change.index < messages.length`, and formatting functions did not guard against null or undefined array items. Additionally, non-essential artifact generation (`writeProjections`) was treated as fatal to the agent turn loop even after the LLM response was complete.
2. The genesis cause for the missing baseline was that `deleteSession` wiped the session folder on disk with `fs.rmSync` without removing cached entries from `this.coordinatorMap` in `IpcBridge`. Re-creating or messaging that session ID reused the stale in-memory coordinator whose `this.initialized` was already `true`, skipping `recordBaseline` and appending `turn.started` as seq 1 to a fresh disk log while holding hundreds of in-memory folded message references.

**Rule:** In event log projection handlers, always validate that index-based modifications fall strictly within current bounds (`0 <= index < length`) and filter out empty elements; make transcript and text formatters skip null/undefined entries safely. Make post-turn projection file writes (`writeProjections`) non-fatal in the coordinator loop and log failures with `console.warn`. In session management, always evict all coordinator cache entries (and abort active abort controllers) on session deletion so re-created sessions always re-initialize their baseline state.
