# A PR branch can lead its worktree, and a missing .bin symlink silently skips GUI tests

- **Trap:** #243's worktree sat at `9e9ee63` while the pushed PR head was `553cf16` (a stub-fix commit from another session). A clean `git status` and a normal `git log -1` hid the gap; rebasing the local commit would have dropped the pushed fix and reintroduced the live-backend gallery failure. The same worktree had the Electron app and `dist/` but no `node_modules/.bin/electron` symlink, which makes the real-window `skipReason()` skip the test silently.
- **Root Cause:** a worktree keeps its own branch pointer, so a push from elsewhere does not move it. `node_modules/.bin` links are created by install, and a worktree can have the package without the link.
- **Rule:** before editing or rebasing a PR branch, run `git fetch origin` and check `git log --oneline HEAD..origin/<branch>`; with a clean tree, `git reset --hard origin/<branch>` when the remote leads, then rebase. Before trusting a real-window result, assert `node_modules/.bin/electron` exists (create it with `ln -sf ../.pnpm/electron@<version>/node_modules/electron/cli.js node_modules/.bin/electron`) and confirm the test actually ran rather than skipped. (OpenSand #243/#245, 2026-11-25)
