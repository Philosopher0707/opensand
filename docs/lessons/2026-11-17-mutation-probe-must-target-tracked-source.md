# A mutation probe must target a tracked source file, and a stale build artifact survives every rebuild

- **Trap:** `git commit` (hooks on) failed on the engine's `timeline-fork` test — "Missing expected rejection" — although the source was clean and `main`'s CI was green. The cause was in the *built* file: `packages/engine/dist/src/missions/manager.js` contained `if (false && active.active)`, a probe mutation left behind by an earlier mutation run whose restore never happened (an interactive `cp -i` prompt hung it). `tsc -b` compared the unchanged source against its build info, decided nothing had changed, and kept the poisoned artifact: every later build and every later test run inherited it. The failure looked like a product bug in a package my change did not touch.
- **Root Cause:** A mutation probe edited a gitignored build artifact, so `git checkout` could not restore it, and an incremental build does not notice that a `dist` file no longer matches its source. Nothing in the test suite compares a build artifact with its source, so the poison survived indefinitely.
- **Rule:** Probe a file git tracks, never a build output: `scripts/mutate.sh` now refuses a target `git ls-files` does not know, because a mutation there is not a real mutation (the next build discards it) and cannot be restored from git. After any probe, restore from the saved copy with `/bin/cp -f` (never `cp`, which is aliased to `cp -i` here) and confirm the restore with `diff -q`; when a test fails only on this machine while the same commit is green in CI, suspect a stale artifact first: `find packages -name dist -type d -exec rm -rf {} +` and rebuild from scratch before reading the failure as a product bug.

(Found while landing the proof scripts: the commit hook failed on a test whose package was byte-identical to `main`. The lesson was already written down in `docs/lessons/2026-11-16-hook-build-stalls-when-syspolicyd-is-stuck.md` — the `cp -i` part — and the new part is that the poisoned file was a build artifact, so neither git nor an incremental build could clean it.)
