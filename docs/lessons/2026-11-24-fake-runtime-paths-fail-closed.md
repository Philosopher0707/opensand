# Fake runtime paths must fail closed, including legacy state

**Trap:** The desktop preload comment promised a test mock but the code instead swallowed every bridge failure. Connector OAuth minted `oauth_<provider>_<hex>` tokens, invented account names, stored `connected`, and the callback accepted a missing code as `mock_code`. The GitHub readiness tool trusted that stored state. `mockNetwork` defaulted to `true` but was never read, while `testConnection()` reported a successful verification without any network call.

**Root Cause:** Test/offline behavior was represented as a production default or a success state instead of an explicit unsupported capability. The placeholder token had no single validator, so both newly minted and previously persisted values could be shown as a real sign-in.

**Rule:** Production entry points must not silently substitute mocks. Preload failures throw and the main process shows a clear error before quitting; OAuth without a configured client ID or a real token exchange returns `501 Not Implemented`; legacy placeholder credentials are demoted synchronously on load, removed from the vault, and rejected by token configuration and GitHub credential resolution. A connection test that cannot reach the provider reports `ok: false` and says it is unverified. Regression coverage: `packages/desktop/test/preload.test.ts`, `packages/desktop/test/hidden-window.test.ts`, `packages/desktop/test/desktop-server.test.ts`, `packages/coordinator/test/connectors.test.ts`, and `packages/coordinator/test/github-client.test.ts`.

**Verification hurdles (2026-11-24):** A fresh worktree's package-only desktop build failed because workspace dependency `dist/` output did not exist; build the dependency closure with `pnpm --filter @opensand/desktop... run build`. A VM test of compiled `preload.cjs` initially failed on missing CommonJS `exports`, not on product behavior; execute compiled CJS with its real module globals. A repeated `finally` block made a broad edit duplicate a test; use unique surrounding context instead of `replaceAll` when the repeated text is structural. Type a fake event bus explicitly before compiling its test. The fresh pnpm install also lacked Electron's `path.txt`/binary, so the full gate spent 15 minutes attempting a download and two engine tests timed out under contention; verify the exact local Electron binary before the gate, and run failed files alone to separate environment/contention from a regression before retrying the full suite. A mutation probe invoked from the repo root must `cd` into the package before running compiled tests. zsh reserves `$status` as read-only; capture command exit codes in `$rc`.
